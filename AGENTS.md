# User Preferences & Instructions

- Always reply and communicate with the user in Tamil (தமிழ் மொழியில் மட்டும் பதில் அளிக்கவும்).
- Maintain all technical details, file paths, commands, code blocks, metrics, and logs clearly while providing explanations and summaries in Tamil.
- Structure replies cleanly and neatly with:
  - Short summary (சுருக்கம்)
  - Changes done (செய்யப்பட்ட மாற்றங்கள்)
  - Newly added / done items (புதிதாகச் செய்யப்பட்டவை)
  - Relevant links included in the response (தொடர்புடைய இணைப்புகள்)
